# Data Structures Coursework

C implementations and experiments with sorting, stacks, balanced trees, Huffman coding, hashing, and graphs.

## Original coursework

- Data Structures

Originally completed at the University of Texas at San Antonio and imported to GitHub later. This repository retains the coursework implementation with documented maintenance fixes and demonstration assets.

**Languages and technologies:** C, Make.

## Implementation

- Insertion-sort and hybrid quicksort runtime experiments.
- A linked-list stack.
- Tree operations including AVL rotations and Huffman-related helpers.
- Hash tables, adjacency structures, and graph traversal utilities.

## Concepts

- Asymptotic behavior, dynamic memory ownership, recursive tree operations, hashing, and graph representation.

## Repository layout

| Directory | Contents |
|---|---|
| `sorting-benchmarks` | Sorting implementations and timing harness |
| `linked-list-stack` | Stack implementation and demo |
| `trees-and-huffman` | Submitted tree.c implementation |
| `hash-table-graph` | Hash-table/graph modules |

## Running the source

Build each directory independently with a C compiler. Supplied Makefiles are retained. The tree exercise requires the original tree.h/Data dependencies, which are missing from this submission.

## Scope and limitations

- The sorting harness contains explicitly supplied course code.
- trees-and-huffman is a partial submission with missing headers; no replacement solution was fabricated.

Only source code, build configuration, and required text inputs are included. Written submissions, assignment instructions, PDFs, videos, generated outputs, binary builds, and private configuration are omitted. Anonymized contributor labels and supplied-code comments retain the distinction between submitted work and scaffolding. No license for course-provided material is inferred.
